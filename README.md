# 使用说明

## 环境搭建

### Node.js

安装 **Node.js 22 或以上版本**，并将安装目录加入环境变量 **PATH**。重新打开终端，确认以下命令可用：

```sh
node -v
npm -v
```

浏览器需支持 WebGL，播放动画或音视频时请开启硬件加速。

## 安装与启动

下载并解压文件，在包含 `package.json` 的目录打开终端，运行：

```sh
npm ci
npm start
```

浏览器会自动打开，也可手动访问 `http://127.0.0.1:8787`。

Windows 用户可以双击 **`start.cmd`**，首次启动时会自动安装运行依赖。

端口被占用时，运行：

```sh
npm start -- --port 8788
```

然后访问 `http://127.0.0.1:8788`。关闭服务时，在终端按 **Ctrl+C**。

## 安装游戏模块

1. 首次启动后进入 **“安装游戏模块”** 页面，也可点击侧栏底部的 **“模块”** 入口。
2. 输入发行者提供的授权码，点击 **“验证并安装”**。
3. 等待自动下载和安装完成，点击 **“进入收藏库”**。

已有模块不会被覆盖。安装失败时，重新提交授权码即可重试；授权码失效时，联系发行者获取新的授权码。

## 日常使用

1. 在首页选择已安装的游戏模块。
2. 点击 **“拉取新角色”** 更新列表；使用 **“导入角色清单”** 的模块，按提示选择包含响应内容的 HAR 文件。
3. 使用搜索、筛选和排序查找角色；点击收藏按钮保存常用角色。
4. 打开角色，按需下载立绘、CG、动画、语音或剧情，也可选择下载全部资源。
5. 下载完成后，在对应分类浏览或播放。缺少播放器界面时，按页面提示下载或检查界面资源。

下载中断后可重新执行原操作，已完成的文件会被复用。页面未更新时点击 **“刷新”**，并查看任务提示。

## 更新、备份与迁移

- **更新程序：** 先关闭服务，保留 `games/` 中已安装的模块和整个 `parsed-data/` 文件夹，再更新程序文件。
- **备份或迁移：** 关闭服务后，复制 `games/` 和 `parsed-data/`；恢复时放回对应位置。
- **清理下载缓存：** 关闭服务后，可删除 `parsed-data/<模块标识>/cache/`。保留 `metadata/`、`state/` 和 `library/`，后续重新处理资源时可能需要再次下载原件。

## 常见问题

- **无法启动：** 确认 `node -v` 和 `npm -v` 可用，再运行 `npm ci`。
- **无法下载：** 检查网络后重试；使用代理时，确认 Node.js 进程可以通过代理连接。
- **动画或音视频无法播放：** 检查浏览器的 WebGL 支持和硬件加速设置。
